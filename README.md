# Orcaru

AI-powered content creation platform that transforms long-form source material into multi-format social media and marketing outputs.

## Tech Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS v4
- Radix UI + shadcn/ui components
- Recharts, Framer Motion, React DnD

## Getting Started

```bash
npm install
npm run dev
```

The dev server runs at `http://localhost:5173/`.

## Build

```bash
npm run build
```

Output is in `dist/`.

## Deployment

Configured for Netlify:
- **Build command:** `npm run build`
- **Publish directory:** `dist`
